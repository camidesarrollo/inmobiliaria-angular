# Inmobiliaria

Frontend en Angular 22 (componentes standalone). Requiere Node.js 22.22+ o 24.15+.

## Desarrollo

```bash
npm install
npm start          # http://localhost:4200
```

La app consume la API de `../server` en `http://localhost:3000`.

## Build

`npm run build` genera la versión de producción en `dist/inmobiliaria`.

## Tests

`npm test` ejecuta los tests unitarios con Vitest.
